## 交付要求

用 bridge-worker，交 delivery.json。先认领本通道请求；长命令用 bw_run.py 并指定两种超时；
数字登记为可回源的 claim，用 bw_render.py 生成报告；用 bw_finish.py 自检后交回执。
delivery.json 使用 bridge-delivery/1，产物带 SHA-256；路径相对于 delivery.json 所在目录或使用绝对路径。
兜底次数必须回源。偏离须以本任务书具体小节作为 authorized_by；待授权决定列入 pending_confirmation。
资源释放后附日志；不能验真的项列入 unverified。未完成时如实交 blocked/failed 并列明第一条原因。
