# 常见报名字段清单

解析材料文件夹时对照本清单提取。不同类型报名要求差异很大，按目标报名类型取子集，不要强行填满。

## 基本身份

- 姓名（与证件一致）、曾用名
- 性别、民族、出生日期
- 政治面貌（群众 / 共青团员 / 中共党员，入党时间）
- 身份证号、证件有效期
- 户籍所在地、生源地、籍贯、出生地
- 婚姻状况、健康状况
- 国籍（涉外报名）、护照号

## 联系方式

- 手机号（是否要求可接收短信验证）
- 电子邮箱
- 通讯地址 + 邮政编码
- 现居住地（省市区）
- 紧急联系人：姓名、关系、电话

## 教育背景

- 最高学历、学位
- 毕业院校、院系、专业
- 入学时间、毕业时间、学制
- 学习形式（全日制 / 非全日制）
- 学籍验证码 / 学历证书编号 / 学位证书编号（学信网报告里有）
- 主要课程成绩、GPA、排名（部分报名要求）
- 外语水平：CET-4/6 分数、雅思托福等
- 计算机等级、其他技能证书

## 工作与经历

- 工作单位、单位性质、职务、职称
- 参加工作时间、工作年限
- 工作经历（起止时间、单位、岗位、职责）逐段
- 项目经历、科研成果、论文发表
- 奖惩情况（获奖名称、级别、时间）
- 家庭主要成员（姓名、关系、工作单位、职务）——公务员/事业编常见

## 报名选项（通常需用户临场决定）

- 报考类别 / 岗位代码 / 项目名称
- 考点城市 / 考区选择
- 场次 / 批次
- 是否服从调剂
- 是否应届生、基层工作经历年限
- 各类承诺与声明勾选

## 常见附件及规格

- 证件照：常见要求 jpg 格式、白底或蓝底、295x413 像素（一寸）或 413x579（二寸）、20KB-100KB 之间；各站点差异大，填表前核对目标网站的具体要求
- 身份证正反面扫描件（jpg/pdf）
- 学历、学位证书扫描件
- 学信网学籍/学历验证报告（带在线验证码）
- 成绩单（教务处盖章版）
- 简历（部分要求 pdf）
- 获奖证书、资格证书扫描件
- 工作证明 / 单位同意报考证明

## 材料与字段的常见对应

- 身份证扫描件 → 姓名、性别、民族、出生日期、身份证号、户籍地址
- 学信网验证报告 → 学校、专业、学历、学制、入学/毕业时间、验证码
- 旧报名表 → 几乎所有字段，最优先解析
- 简历 → 联系方式、教育经历、工作经历、技能证书
- 成绩单 → 课程成绩、GPA
